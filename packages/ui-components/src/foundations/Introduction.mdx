# BipUI

Librería de componentes React con TypeScript, CSS Modules y tokens de diseño. Sin dependencia
de Tailwind ni otra herramienta de CSS.

## Instalación

```bash
pnpm add @bip-design-systems/ui-components
```

Requiere React 18+ (o 19) y Node ≥ 20.

## Setup

Importa el CSS compilado una sola vez en el punto de entrada de tu app:

```ts
// src/main.tsx
import '@bip-design-systems/ui-components/style.css';
```

Envuelve tu app con `ThemeProvider` — es opcional (sin él, el tema por defecto es
`square`/`light`), pero es el punto de entrada para theming, dark mode, RTL y density:

```tsx
import { Button, ThemeProvider } from '@bip-design-systems/ui-components';

export const App = () => (
  <ThemeProvider theme="rounded">
    <Button variant="primary">Hola BipUI</Button>
  </ThemeProvider>
);
```

## Theming en runtime

`ThemeProvider` acepta overrides sin paso de build, estilo Ant Design `ConfigProvider`:

```tsx
<ThemeProvider
  theme="rounded"
  tokens={{ colorPrimary: '#e2007a', dark: { colorPrimary: '#ff4fa8' } }}
>
  <App />
</ThemeProvider>
```

Ver [Foundations/Theming](/docs/foundations-theming--docs) para el playground completo
(seeds editables, panel de contraste WCAG, snippet copiable).
